# NoteNest

A simple notes app. Add a note, give it a category (Personal, Work, Idea,
Study, or To-do), search through your notes, and filter by category. Notes
are saved in your browser's local storage, so they're still there when you
come back.

## Running it locally

No installation needed.

1. Clone the repo (or your fork of it)
2. Open `index.html` directly in your browser

That's it. There's no server, no `npm install`, nothing to build.
